# `docs/archive/` — research log

These files are kept on purpose. They record how the engine got where it is: superseded plans, earlier audits,
measurements, and the ideas that were tried and refuted, with the numbers that refuted them. Most of the project's work
was measurement, and a negative result saved here is one nobody has to re-run.

They are historical: written at the time, in the working voice of the time, and not updated since. Statements about
"current" state, file names, baselines or next steps in them may be stale. For the present state see
[`ROADMAP.md`](../../ROADMAP.md); for how changes are measured, [`CONTRIBUTING.md`](../../CONTRIBUTING.md).

Good entry points:

- `CLAUDE_HISTORY.md` — the investigation log: win-rate audits, operating-point results, refuted levers, findings from
  the human-run dataset.
- `WINRATE_AUDIT.md`, `WINRATE_AUDIT_v2.md`, `WINRATE_V3_PLAN.md`, `WINRATE_V4_PLAN.md` — the successive win-rate
  plans and audits, in order.
- `HISTORY.md` — an older index of these superseded planning documents and what replaced each.
